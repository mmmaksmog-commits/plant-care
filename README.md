# 🪴 Мои растения

**График полива комнатных растений.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/plant-care/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Своё расписание для каждого растения
- Растения грустят и вянут, если про них забыть
- Список «полить сегодня» и история за 2 недели
- 8 видов растений с рекомендованным поливом

## Стек

JavaScript, CSS-анимации. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/plant-care.git
cd plant-care
python3 -m http.server 8000
```
